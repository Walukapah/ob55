## 🔧 Lᴏᴄᴀʟ JWT Gᴇɴᴇʀᴀᴛᴏʀ

The app tries the remote token API first, and if it is unreachable it generates
the token itself with `jwt_gen.py` (guest OAuth → `MajorLogin`).

```bash
python jwt_gen.py <uid> <password>        # test one account, token is masked
python import_tokens.py jwt_token.json --server SG --login-url https://<api host>
```



| Env var | Default | Use |
|---------|---------|-----|
| `FF_LOCAL_JWT` | `1` | set `0` to disable local generation |
| `FF_MAJOR_LOGIN_URL` | ggblueshark → ppmainecoonghj | login endpoint (tried in order) |
| `FF_X_GA_SV` | `1789556611` | mandatory header — omit it and MajorLogin answers `400 SignError1` |
| `FF_RELEASE_VERSION` | `OB55` | `ReleaseVersion` header |
| `FF_OAUTH_URL` | Garena guest OAuth | guest token grant |
| `FF_LOGIN_URL_<REGION>` | built-in map | overrides the `Login_url` for a region, e.g. `FF_LOGIN_URL_SG` |

`import_tokens.py` converts a raw `[{"token": "..."}]` dump into `token_*.json`
(uid, expiry and region are read out of each JWT).
